# Daggerfall Unity Quest Token Dictionary

A comprehensive, centralized reference guide for Daggerfall Unity quest modders. This list provides descriptions for plain-text scripting macros, behavior network symbols, formatting codes, and dialogue tags.

## How to Search
Every token features consistent, bracketed category tags at the end of the line. Use **`Ctrl + F`** to instantly search the `quest_tokens.md` file by category:
* **`[NPC]`** - Quest givers, enemies, companions, or unique contacts.
* **`[Location]`** - Castles, houses, dungeons, temples, or shops.
* **`[Item]`** - Letters, artifacts, gear, gold, or quest loot.
* **`[Faction]`** - Political kingdoms, guilds, knightly orders, or covens.
* **`[Trigger]`** - Timers, runtime events, menu clicks, or script switches.


Disclaimer: I let Gemini make the keywords to search these, and to define them all. I did not go through all the definitions.
